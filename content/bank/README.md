# Question bank

Bundled study questions for Computing Systems Arena. The app loads `data/` by default.

| Path | Contents |
| --- | --- |
| `schema/question.schema.json` | JSON Schema for one question |
| `data/weeks/week-01.json` … `week-13.json` | Week title, goals, traps, summary, and questions |
| `data/mock-test.json` | The 40-question mock and its answer key |
| `data/bosses.json` | 25 long-answer prompts and the shared 5-step rubric |
| `data/flashcards.json` | Summary cards and the course cheat sheet |

`source` is `quiz` (shown in the app as Practice quiz), `extra`, or `mock`. Quiz ids look like `W02-Q014`. Extra ids look like `W02-X03`. Questions with `needsReview: true` stay in the deck and show an unverified badge.

Questions and answers are AI-assisted study material, not official course content; verify against your course resources.
